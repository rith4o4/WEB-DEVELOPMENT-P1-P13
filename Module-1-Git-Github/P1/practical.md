# P1: Project Folder and Terminal Navigation

## Aim
To create and organize a project folder and practise basic terminal navigation and file-management commands.

## Concepts
- `pwd` displays the current working directory.
- `ls` lists files and folders.
- `mkdir` creates a directory.
- `cd` changes the current directory; `cd ..` moves to its parent.
- `touch` creates an empty file.

## Procedure
1. Open the terminal in the location where the project should be stored.
2. Create the main project directory and navigate into it.
3. Create the required module and practical directories.
4. Create a sample file and list the directory contents to verify it.

## Commands
```bash
pwd
ls
mkdir -p Web-Development-Lab/Module-1-Git-GitHub/P1
cd Web-Development-Lab/Module-1-Git-GitHub/P1
touch p1_notes.txt
ls
```

## Result
The project directory was created and basic terminal navigation and file-creation commands were practised.
