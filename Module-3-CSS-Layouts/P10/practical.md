# P10: Portfolio Header and Footer with Advanced Flexbox

## Aim
To design portfolio header and footer sections using advanced CSS Flexbox alignment and distribution properties.

## Concepts
Flexbox properties such as `justify-content`, `align-items`, `align-content`, `flex-wrap`, `flex-grow`, `flex-shrink` and `gap` help arrange items and manage available space.

## Procedure
1. Create semantic header and footer regions in HTML.
2. Group the logo or portfolio title and navigation items in the header.
3. Apply Flexbox to arrange and align header content.
4. Create footer groups such as contact information, navigation or social links.
5. Use wrapping, gaps and alignment properties to handle different available widths.
6. Test the header and footer at different viewport sizes.

## Result
Portfolio header and footer layouts were arranged using advanced Flexbox properties.
