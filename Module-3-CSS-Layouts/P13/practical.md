# P13: Choosing Between Flexbox and Grid for a Shared Layout

## Aim
To compare Flexbox and CSS Grid and choose an appropriate layout system for different parts of a shared page layout.

## Concepts
Flexbox is generally suited to arranging items along one primary axis. Grid is suited to layouts that coordinate rows and columns together. Both systems can be combined in one page.

## Procedure
1. Identify the page regions and the layout needs of each region.
2. Use Flexbox for components that primarily need one-dimensional alignment, such as a row of navigation items.
3. Use Grid for areas that need coordinated rows and columns, such as a project or content layout.
4. Combine the systems where appropriate, with Grid controlling the larger page structure and Flexbox arranging items inside components, or vice versa.
5. Test the shared layout at different viewport sizes and adjust responsive rules.
6. Review whether each layout choice matches the structure of its content.

## Comparison
| Flexbox | CSS Grid |
|---|---|
| Primarily one-dimensional | Two-dimensional rows and columns |
| Useful for aligning items in a row or column | Useful for structured page and card layouts |
| Content-driven distribution along an axis | Explicit control over tracks and placement |

## Result
Flexbox and Grid were compared and applied to suitable parts of a shared layout.
