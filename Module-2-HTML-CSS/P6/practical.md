# P6: Full Portfolio Page Structure in Semantic HTML

## Aim
To build the complete structural layout of a portfolio page using semantic HTML.

## Concepts
Semantic page structure separates content into meaningful regions such as site header, navigation, main content, sections and footer. Navigation links should point to the relevant section identifiers.

## Procedure
1. Create an HTML5 document with a descriptive title and viewport metadata.
2. Add a `header` containing the portfolio identity and a `nav` with section links.
3. Create a `main` region containing suitable portfolio sections, such as introduction, about, skills, projects and contact.
4. Use headings, paragraphs, lists and links appropriate to the content.
5. Add a `footer` and verify that navigation links target existing section IDs.
6. Open the page in a browser and check the structure and links.

## Result
A full portfolio page structure was created using semantic HTML.
