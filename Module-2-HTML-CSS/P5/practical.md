# P5: Semantic Bio Page

## Aim
To create a personal biography page using meaningful semantic HTML elements.

## Concepts
Semantic elements describe the role of content. Suitable elements may include `header`, `main`, `section`, `article`, and `footer`. Heading levels should follow a logical hierarchy.

## Procedure
1. Create an HTML document with the standard HTML5 structure.
2. Add a page header with the person's name and a short introduction.
3. Use clearly labelled sections for biography, interests, education or skills, as applicable to the task.
4. Use semantic elements and appropriate headings instead of relying only on generic containers.
5. Add relevant links or images if required, then open the page in a browser.

## Key HTML elements
```html
<header>...</header>
<main>
  <section>
    <h2>About Me</h2>
    <p>...</p>
  </section>
</main>
<footer>...</footer>
```

## Result
A biography page was structured using semantic HTML elements.
